# Jeu de la Vie

Une simulation interactive de l’automate cellulaire imaginé par John Conway. Placez des cellules sur la grille, lancez l’évolution et observez les motifs apparaître selon les règles du Jeu de la Vie. L’interface permet aussi d’explorer des motifs et d’importer ou d’exporter des configurations.

[Ouvrir le Jeu de la Vie](https://breizhimic.github.io/JeuDeLaVie/)
